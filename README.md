### What I Learned

This project helped me become more comfortable with semantic HTML and responsive CSS. I also learned how to:

- Use `@font-face` to load local fonts.
- Center content with CSS Grid.
- Build layouts with Flexbox.
- Create hover effects for interactive elements.
- Use `rem` units for spacing and typography.
- Match a design by adjusting spacing, shadows, and typography.

One piece of CSS I'm proud of is the hover effect on the blog title.

```css
h1 a{
    color: hsl(0, 0%, 7%);
    text-decoration: none;
    transition: color 0.2s ease;
}

h1 a:hover{
    color: hsl(47, 88%, 63%);
}
```
